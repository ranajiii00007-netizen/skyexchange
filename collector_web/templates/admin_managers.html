👑 About Manager Admins

Manager Admins have **full read and write access** to the system (same as the default Super Admin). They can manage transactions, customers, bankers, collectors, rates, and reports.

However, they **cannot** access the Manager Admin management page or view the system action logs. Those pages are restricted to the default Super Admin only.

Every action they perform (editing rates, deleting transactions, etc.) is recorded in the **Audit Logs** along with their specific username and IP address.
